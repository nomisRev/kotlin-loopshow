# Kotlin changelog cache

Snapshot of the Kotlin "what's new" pages (2.2.0 → 2.4.20 plus the EAP page for 2.5.0-Beta1),
the language feature status table and the Kotlin roadmap, pulled from the
[kotlin-web-site](https://github.com/JetBrains/kotlin-web-site) sources on the date in
`last-refresh.txt`. `releases.txt` lists the latest GitHub release tags.

Run `./refresh.sh` to update. The topic plan in `../../PLAN.md` was derived from this snapshot.
