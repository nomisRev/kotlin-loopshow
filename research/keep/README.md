# KEEP cache

Snapshot of the [Kotlin KEEP repository](https://github.com/Kotlin/KEEP) (Kotlin Evolution and
Enhancement Process) on the date in `last-refresh.txt`, at the upstream commit in `upstream-commit.txt`.

- `proposals/` — the KEEP design documents (`KEEP-NNNN-name.md`), plus `stdlib/` and per-proposal subfolders
- `notes/` — design notes that are not full proposals
- `resources/` — images and benchmarks the proposals link to
- `KEEP-README.md` — the upstream README with the status of each KEEP
- `index.txt` — one line per proposal file

Run `./refresh.sh` to update.
